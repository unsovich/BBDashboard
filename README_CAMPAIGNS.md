# Campaign Monitoring Module - Quick Start

## 🚀 Быстрый старт

### Запуск приложения

```bash
cd /Users/unsovich/AntigravityProjects/BBDashboard
streamlit run main.py
```

### Первое использование

1. В боковом меню выберите **"Мониторинг Кампаний"**
2. Перейдите на вкладку **"➕ Новая кампания"**
3. Создайте первую кампанию с тестовыми данными
4. Изучите все вкладки для знакомства с функционалом

## 📊 Основные метрики

| Метрика | Формула | Норма |
|---------|---------|-------|
| ROI | (Доход - Затраты) / Затраты × 100% | > 250% |
| CoF | Затраты / Доход | < 0.3 |
| CTR | Клики / Охват × 100% | > 1% |
| DCR | Доноры / Клики × 100% | > 2% |

## 🚨 Красные флаги

- **Критично** (ROI < 250%): Немедленная остановка кампании
- **Внимание** (ROI < 350%): Требуется оптимизация
- **Низкий CTR** (< 1%): Проблема с таргетингом
- **Низкий DCR** (< 2%): Слабая доказательная база

## 💡 Советы

- Регулярно обновляйте метрики кампаний
- Следите за красными флагами
- Используйте сравнение каналов для оптимизации бюджета
- Экспортируйте отчеты для ЕОС в формате Excel

## 🆘 Устранение проблем

**Модули не загружаются**:
- Убедитесь, что папка `modules/` находится в директории с `main.py`
- Проверьте, что все файлы модулей созданы

**Данные не сохраняются**:
- Создайте папку `data/` вручную
- Проверьте права доступа на запись

**Ошибки при расчете метрик**:
- Убедитесь, что все числовые поля заполнены корректно
- Проверьте, что даты указаны правильно (старт < окончания)
